# 901 Education Onboarding

A React and TypeScript app that displays teams and retrieves their approval
status through a simulated Wix Custom Element workflow.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed in the terminal. Click a team to select it and
view its `Approved` or `Pending Approval` status.

## Verify

```bash
npm run build
npm run lint
```
